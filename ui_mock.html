Chapter 00: Gemini StreamAssist Studio Guide

Functional Areas, Operational Modes, and Interactive Features

Studio v1.0

Gemini StreamAssist Studio is a local developer tool and visual reference for building against the Gemini Enterprise streamAssist API.

⚡ 1. Dual-Mode Switcher

Seamlessly toggle between Offline Simulator (17 captured fixtures from outputs/) and Live Cloud Runner (invoking Google Discovery Engine via ADC & .env).

🔬 2. Wire Stream Inspector

Step-by-step token playback of chunked HTTP 200 JSON arrays, raw bytes vs assembled UI, thought accordions (thought: true), and Gotcha #9 mid-stream error alerts.

🛠️ 3. Chat Simulator & Code Gen

Visual request builder with real-time schema validation and instant polyglot code synchronization (cURL, Python SDK, Node.js, and raw JSON).

🧪 4. Agent Routing Diagnostic

Interactive debugger for Gotcha #2: Inspects plannerSteps to confirm whether a query successfully delegated to an agent function or fell back to the base orchestrator.

📁 5. Sessions & Files Workspace

Multi-turn session manager with query/token correlation, context file explorer (:listSessionFileMetadata), and Recipe A copilot runner.

🔍 6. Deep Research Flow

Two-step protocol visualizer: Step 1 research plan editor & approval checklist ➔ Step 2 execution monitor filtering by contentKind.

📊 7. Test Suites Dashboard

Interactive execution harness for all 12 smoke tests (scripts/run-all.sh) plus a 24-hour Cloud Run soak benchmark monitor with P50/P90 latency metrics.
