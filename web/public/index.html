API Glossary & Vocabulary

        
      

      

        

          
agentsSpec

          
Scopes the orchestrator planner to consider a specific subset of configured agents. Note: scopes, does not guarantee force (Gotcha #2).

        

        

          
assistToken

          
Opaque token returned on nearly every response chunk. Used for correlation and Google Cloud support incident tracing.

        

        

          
contentKind

          
Type marker on response chunks (e.g., RESEARCH_PLAN, RESEARCH_QUESTION, RESEARCH_REPORT). Essential for Deep Research demuxing.

        

        

          
Thought (thought: true)

          
Interleaved reasoning steps generated by the model. Must be demuxed and filtered away from user-facing answer markdown (Gotcha #10).
